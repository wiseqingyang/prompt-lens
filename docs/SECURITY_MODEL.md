# 安全、隐私与信任边界

## 数据流与网络

Agent 显式使用本地代理 → Go 转发原始业务流量 → 经认证的本地审计事件 → Electron 主进程解析与 SQLite → 受认证的 Web API / 受校验的 IPC → Vue 界面。

非捕获域名走隧道；捕获域名的 HTTPS 由本地 CA 解密，代理仍校验真正上游证书。`chatgpt.com` 的模型路径过滤发生在解密之后，因此信任边界覆盖整个该域连接，不能描述为仅能读取模型路径。不要添加与研究无关的域名。该机制可能与证书固定、客户端策略或使用约定不兼容。

上游 `system` 模式读取应用启动时的环境变量，没有值则直连，不自动读取/修改系统网络配置。应用启动、Agent 一键启动、用户点击连接测试会产生各自的网络流量；连接测试访问 Google Generative Language 域的 HEAD 或 CONNECT，不发送模型提示词。依赖安装和构建工具也会联网。不存在应用自建的远程审计收集服务。

## 本地存储

默认目录 `~/.prompt-lens/` 保存配置、SQLite、CA、私钥及审计重试材料；Electron 的用户数据目录另外保存窗口/Web 会话状态。具体数据库路径在设置中显示。目录/文件权限是本机隔离手段，不防范同账户恶意程序、管理员或设备失窃；应用没有数据库加密。

Authorization、Cookie、API Key 等已知认证头只在审计副本中脱敏，不修改原业务请求。请求正文、工具参数、响应和 URL 自由文本可能含秘密。默认保留期 0 表示永久保留；“原始正文期限”和“记录期限”是不同策略。空间回收或删除 SQLite 记录不等同于对磁盘、系统备份和导出文件的安全擦除。

配置中的带用户名/密码上游 URL 必须交给代理使用，会保存在本地配置；不要分享配置文件。诊断中的上游地址会去除认证信息。导出使用有限的模式规则，无法自动识别所有凭据和个人信息；人工检查后才可分享。

## 控制面

Web 服务仅监听回环地址。API 要求随机运行密钥，精确校验 Host/Origin 和 Cookie；首次浏览器引导将 token 换成 HttpOnly、SameSite=Strict 会话 Cookie 后重定向。健康接口公开提供就绪信息。其他本地端口在同一主机 Cookie 安全边界内，不能把回环服务等同于对同账户恶意程序的防御。

Electron 使用上下文隔离、沙箱、禁止 Node 集成、CSP、主窗口/主 frame IPC 来源校验与参数校验。外部导航、弹窗及非必要权限被拒绝。CSP 的样式规则允许 Vue 动态内联样式；不允许内联脚本。认证后的用户可读取和删除审计记录、修改配置或请求安装 CA，应保护浏览器会话。

## CA 生命周期

新目录由 Go 核心生成独立 CA；不自动继承其他代理工具私钥。旧版本已经生成/导入的 CA 不被静默轮换。证书状态区分缺失、无效、过期、未信任、受信任与无法确认。系统验证通过不代表所有 Agent 独立证书库都认可该 CA。

安装信任需要用户主动操作；卸载应用不会自动撤销。曾使用旧版自动导入 CA 的用户应核对指纹和其他工具的依赖后决定是否移除。损坏 CA 不自动修复，恢复步骤见 [卸载与恢复](UNINSTALL.md)。
