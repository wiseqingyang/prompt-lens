# ADR 0002：按 Agent 分离可重算的会话与轮次归属

- 日期：2026-10-14
- 状态：采纳
- 2026-10-15 修订：自动接入与简化展示，替代默认关闭与页面诊断展示。
- 2026-10-15 修订：证据独立保存，后台采集与本地回放分离，规则版本 2。

## 决策

捕获记录是事实来源；会话与轮次是带规则版本的派生结果。`AttributionService` 是 HTTP/IPC 的共同查询入口，注册表选择唯一适配器；适配器负责提取字段、重解析原文、核对历史证据和纯规则判定，文件源负责只读 I/O，仓储分别保存不可变观察和可重算结果，展示映射负责导航 DTO。捕获 ACK 不等待本地日志，不重放模型请求。

第一个适配器实现 Antigravity。会话以有效 cascade_id 与结构化 requestId 为依据，冲突或缺失进入特殊待归属组。原生 USER_EXPLICIT 与 USER_INPUT 同时成立才是用户输入事件；step_index 只定位事件与请求，不以数字变化切分轮次。共享 sessionId、相同文本、执行 ID、时间间隔均不作为归属兜底。时间仅检查证据是否晚于捕获，不产生会话或轮次。

本地证据源自动发现当前用户 `.gemini/antigravity` 下的 brain 与 conversations 目录，自定义路径优先。抓包记录与采集待办同事务提交；后台一次最多处理 32 条，优先新请求，未找到完整证据时退避补采（上限 60 秒），重启继续未完成待办。源文件读取与页面查询分离；页面只使用本应用已保存证据。

原始 transcript JSONL（保留未知字段、完整用户/工具正文）与 trajectory_meta 身份字段按受限大小采集，保存格式版本、位置和观察时间，按内容哈希去重并压缩。规则解释只保留所需字段；升级可重新解码原文，历史 v13 快照没有原文则明确保持原有精度。观察按 Agent/会话/轨迹共享，独立于规则版本，追加或冲突均保留历史；引用单独保存，避免每个请求复制全套观察。

源删除、暂时不可读或截短不否定已保存的事件；步骤重叠且内容不一致时保留冲突，不因恢复旧文件而清除。证据不足时保持未知，绝不拼接不相交的残缺日志推造完整前缀。正文过期或记录删除时清除对应派生行、待办与引用；共享观察在最后引用移除时清理。

## 扩展约束

新增 Agent 应增加独立适配器，按需要注册证据源及合成契约测试；不要向查询编排或 Vue 添加协议分支。现有证据契约先覆盖已验证的原生轨迹格式，新协议需要新证据结构时显式扩展类型，而非伪造 Antigravity 步骤。规则变更递增版本，并验证历史快照重放与新旧结果差异。

其他 Agent 暂时走原聚合流程。既有 API 的 `tasks` / `turns` 在新流程中仅作过渡 DTO，分别映射轮次组与请求引用，业务判定不依赖这些旧命名。UI 左侧选择服务端生成的轮次，右侧仅展示组内请求；不在渲染端再次判定归属。

## 取舍与回退

不引入通用规则 DSL、动态插件加载器或额外消息总线。采集器只在后台读源文件，查询复用应用内快照解析；无变化刷新不重写派生行。超限日志保持未知。首次采集前就被源 App 删除的内容无法恢复。

Schema 14 增加不可变观察、会话/轨迹引用和采集待办，v13 的已有快照在事务内迁入，原始抓包正文不变。旧版不保证保留新结构的语义；降级须退出应用并恢复升级前完整数据库备份，禁止手动调低 user_version。没有真实 Agent 与打包桌面验收证据时不得宣称已验证这些路径。
