# ADR 0001: Go 代理内核

状态：已采用

## 决策与边界

PromptLens 使用 Go 独立进程转发业务流量，Electron 主进程处理审计事件、持久化和界面控制。选择独立二进制便于管理进程生命周期、打包和跨平台构建；本记录不提供未经基准测试的启动时间、内存或吞吐量承诺。

成熟代理 sidecar 是另一种实现选择，可以复用更广泛的协议能力，但需要同时管理它的运行环境、插件和 IPC。当前选择 Go 意味着项目必须自行维护 TLS、转发、取消和资源上限的回归测试。

## 必须保持的契约

- 捕获和脱敏只作用于审计副本，不能改变业务请求或回复。
- 未选中捕获的 HTTPS 目标使用 CONNECT 隧道，保留端到端 TLS。
- 审计投递可以重试；模型请求和工具调用不得因此重放。
- 主进程负责启动、就绪和退出回收；内部审计接收需要认证。
- 协议测试覆盖 HTTP/HTTPS、SSE 与 Responses WebSocket；具体在线 Agent 的兼容性仍须单独验证。

实现入口和测试约束见 [架构](../ARCHITECTURE.md)、[开发流程](../DEVELOPMENT.md) 与 [支持范围](../SUPPORT.md)。早期 Python 试验实现已从当前代码库中移除，生产运行以 Go 代理为单一核心。
