# 支持范围与兼容性

当前提供源码，由个人维护，尚无已验收的正式桌面安装包。源码首发不以 Apple Developer 会员、签名或公证为前提；这些是以后分发 macOS 安装包的独立条件。以下是目标与证据边界。

| 平台 | 当前定位 | 发布前证据 |
| --- | --- | --- |
| macOS Apple Silicon | 主要源码开发目标 | CI 完整门禁；桌面发行另需签名公证、干净设备安装卸载、真实 Agent 验收 |
| macOS Intel | 实验性源码 | 独立 x64 构建、核心架构、桌面/证书/Agent 验收 |
| Linux | 开发和自动化测试目标 | 桌面发行、信任配置和安装验收尚缺 |
| Windows | 实验性源码 | 完整测试、代理、原生模块、证书和安装卸载验收尚缺 |

自动化协议覆盖 HTTP、HTTPS、SSE 和 Responses WebSocket；它不能证明某一在线 Agent 版本支持其代理与证书设置。接入页包含 Antigravity、Codex 桌面端/CLI、Pi、WorkBuddy 和通用终端，真实支持声明必须在发行记录中写明 Agent 版本、系统版本、测试日期和结果。

macOS CA 检查使用系统证书验证；其他平台明确显示“需人工核实”。核心与连接测试仅支持 HTTP/HTTPS 上游代理，不支持 SOCKS。浏览器无法一键启动应用或做桌面连接测试。默认不含远程同步、云存储或自动更新服务。

维护策略：预发行阶段只维护主分支，尚未承诺响应时限或长期支持。正式版本采用语义化版本和 CHANGELOG；新版本不应被当作允许直接降级数据库的承诺。破坏性数据迁移必须有备份、恢复和兼容性说明。


Pi 基础归属适配以明确 Pi 客户端身份后，按 Responses、Anthropic Messages、Chat Completions 的响应 ID 对应 v3 原生会话记录（实现见 `src/main/attribution/adapters/pi.ts`）。默认只读发现 `~/.pi/agent/sessions`，可在「存储 → Pi 会话目录」指定其他目录。缺失或多候选不会猜测归属。规则 3 按原生 message/user 输入条目的 ID 与祖先链分轮，交互、RPC、扩展显式 sendUserMessage 均计入；工具返回、普通上下文注入与压缩不新建输入轮次，不推断人工来源。旧记录由后台补齐祖先证据后重算，无需清库或新增扩展；缺失、冲突和超限仍保留未确认原因。其他 API、无落盘、辅助用途暂不声明支持，真实 Agent 验收另列。
