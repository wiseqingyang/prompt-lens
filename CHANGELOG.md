# Changelog

Changes are grouped by public release. A version in package metadata does not imply that a public release exists.

## Unreleased — initial source distribution

- Local HTTP/HTTPS/SSE and Responses WebSocket request inspection with a Go proxy.
- Electron/Vue views for prompts, tool calls, responses, sessions and token provenance.
- Local SQLite storage, configurable retention, and export redaction for manual review.
- Explicit CA trust and agent setup, authenticated loopback APIs, and isolated renderer IPC.
- Source archives with a reviewed file allowlist, SHA-256 manifests and checksums.
- macOS/Linux quality checks, dependency review and secret scanning.

See the [support matrix](docs/SUPPORT.md) and [release instructions](docs/RELEASING.md). A qualified desktop installer and universal agent compatibility are not yet provided.
